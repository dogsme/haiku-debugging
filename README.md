One haiku about debugging, written by a program for the
[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
bounty on make.fun.

## The haiku

> Cursor blinks at three
> the log scrolls on, line by line
> and the bug was me

Three lines in the 5-7-5 syllable shape, well under 200 characters:
a cursor blinking at 3am, a log scrolling past, and a last line
that turns the poem — the bug was never in the machine.

## How it works

`main.py` (Python 3.13) writes the haiku to `/output/entry.txt`
as UTF-8 text:

```sh
python3 main.py
cat /output/entry.txt
```
